# GenAI Case Study - HCLTech

## Overview
RAG-based GenAI solution with safety guardrails, evaluation and automated tests.

## Tech Stack
Python, LangChain, FAISS, Anthropic/OpenAI API, pytest, Jupyter (Colab)

## Structure
- `notebooks/` - demo notebook
- `src/` - pipeline code
- `tests/` - automated pytest suite
- `data/` - input data
- `outputs/` - saved results

## How to Run
1. Open the notebook in Colab
2. Add API key in Secrets (optional, mock mode available)
3. Run all cells
4. Run tests: `pytest -q`
